# 💅 RASS Studio

> Site e sistema web desenvolvido para um studio de unhas e joias.

O **RASS Studio** é um projeto real criado para apresentar serviços, produtos e facilitar o contato e o agendamento com clientes. O foco do desenvolvimento foi entregar uma experiência elegante, simples e especialmente bem adaptada ao celular.

## ✨ Recursos

- Catálogo de serviços de unhas
- Área dedicada a joias e produtos
- Fluxo de agendamento
- Contato facilitado
- Interface administrativa
- Layout responsivo com prioridade para dispositivos móveis
- Publicação com domínio personalizado
- Arquivos de SEO, sitemap e política de segurança do projeto

## 🛠️ Tecnologias

`HTML5` · `CSS3` · `JavaScript` · `Supabase` · `GitHub Pages`

## 🎯 Objetivo

Este projeto demonstra a aplicação de desenvolvimento web em uma necessidade real: transformar a identidade de um pequeno negócio em uma presença digital funcional, administrável e preparada para clientes.

## 🔐 Boas práticas

Credenciais privadas e chaves administrativas não devem ser armazenadas no frontend ou versionadas neste repositório.
